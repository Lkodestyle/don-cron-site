Política de Privacidad

Fecha de vigencia: 12 de septiembre de 2026. Aplica a la aplicación Don Cron Publish y al sitio don-cron.com.

1. Resumen

Don Cron Publish es una herramienta interna de línea de comandos que usa únicamente el titular del canal Don Cron (Lucas Cristaldo) para publicar sus propios videos en sus propias cuentas de YouTube y TikTok. No tiene usuarios de terceros: nadie más se registra, inicia sesión ni conecta cuentas a través de esta app. Esta política describe qué datos toca la app, con qué fin, dónde se guardan y cómo se pueden revocar.

2. Qué datos toca la app

  • Metadatos del video: título, descripción y hashtags de cada video que se publica.
  • El archivo de video (mp4) que se sube a YouTube y TikTok.
  • Información básica de la cuenta que devuelven las APIs de YouTube (Data API v3) y TikTok (Content Posting API) al autenticarse: identificador del canal/cuenta y estado de la publicación (éxito, error, ID del video publicado).

Todos estos datos pertenecen al propio titular del canal. La app no recolecta datos de espectadores, de otros usuarios de YouTube o TikTok, ni de visitantes de este sitio.

3. Con qué fin se usan

Exclusivamente para publicar los videos del canal Don Cron en las cuentas de YouTube (@Don-Cron) y TikTok (@eldoncron) del propio titular. No se usan con fines publicitarios, de perfilado, ni se comparten con terceros.

4. Dónde se almacenan

Los tokens de autenticación OAuth y los archivos de video se guardan localmente en la máquina del titular, o como secrets cifrados en GitHub Actions cuando la publicación corre en ese entorno. No se almacenan en ninguna base de datos de terceros ni en ningún servidor expuesto públicamente.

5. Retención

Los tokens y los metadatos se conservan hasta que el titular los elimina o los revoca manualmente. No hay un plazo de borrado automático porque no existe una cuenta de usuario que expire: es una herramienta de uso personal y continuo del propio titular.

6. No se comparte ni se vende

Ningún dato tocado por Don Cron Publish se comparte, se vende ni se cede a terceros. La app no tiene integraciones de analítica, publicidad ni monetización de datos.

7. Sin usuarios de terceros

Esta app no ofrece registro ni inicio de sesión a otras personas. No existe una base de usuarios externa cuyos datos deban protegerse más allá de los del propio titular.

8. Cómo revocar el acceso

El titular puede revocar el acceso de Don Cron Publish a sus cuentas en cualquier momento desde:

  • Google: myaccount.google.com/connections (aplicaciones y servicios de terceros conectados).
  • TikTok: configuración de la cuenta → "Seguridad" → "Aplicaciones conectadas", en la app o en tiktok.com/setting.

Además, el titular puede borrar los tokens guardados localmente o los secrets de GitHub Actions en cualquier momento, lo que revoca el acceso local de inmediato.

9. YouTube API Services

Don Cron Publish usa YouTube API Services. Al usarla, se aplican además la Política de Privacidad de Google y los Términos del Servicio de YouTube. Además, la home de este sitio embebe los videos del canal usando el modo de privacidad mejorada de YouTube (dominio youtube-nocookie.com); al reproducirlos también se aplican esas mismas políticas de Google/YouTube.

10. TikTok Content Posting API

La publicación en TikTok se realiza a través de la TikTok Content Posting API (scope video.publish), sujeta a los términos y políticas de desarrolladores de TikTok.

11. Contacto

Para consultas sobre esta política, escribí a cristaldolucas01@gmail.com.

English version

Privacy Policy

Effective date: September 12, 2026. Applies to the Don Cron Publish application and to don-cron.com.

1. Summary

Don Cron Publish is an internal command-line tool used solely by the Don Cron channel owner (Lucas Cristaldo) to publish his own videos to his own YouTube and TikTok accounts. It has no third-party users: no one else signs up, logs in, or connects accounts through this app. This policy describes what data the app touches, for what purpose, where it is stored, and how it can be revoked.

2. What data the app touches

  • Video metadata: title, description and hashtags for each published video.
  • The video file (mp4) uploaded to YouTube and TikTok.
  • Basic account information returned by the YouTube (Data API v3) and TikTok (Content Posting API) APIs upon authentication: channel/account identifier and publish status (success, error, published video ID).

All of this data belongs to the channel owner himself. The app does not collect data from viewers, from other YouTube or TikTok users, or from visitors of this site.

3. Purpose of use

Exclusively to publish Don Cron's videos to the owner's own YouTube (@Don-Cron) and TikTok (@eldoncron) accounts. Data is not used for advertising, profiling, or shared with third parties.

4. Where it is stored

OAuth authentication tokens and video files are stored locally on the owner's machine, or as encrypted GitHub Actions secrets when publishing runs in that environment. They are not stored in any third-party database or on any publicly exposed server.

5. Retention

Tokens and metadata are kept until the owner manually deletes or revokes them. There is no automatic deletion period because there is no expiring user account: this is a personal, ongoing tool used by the owner himself.

6. No sharing or selling

No data touched by Don Cron Publish is shared, sold, or transferred to third parties. The app has no analytics, advertising, or data monetization integrations.

7. No third-party users

This app does not offer sign-up or sign-in to other people. There is no external user base whose data needs protecting beyond the owner's own.

8. How to revoke access

The owner can revoke Don Cron Publish's access to his accounts at any time from:

  • Google: myaccount.google.com/connections (connected third-party apps and services).
  • TikTok: account settings → "Security" → "Connected apps and services", in the app or at tiktok.com/setting.

Additionally, the owner can delete the locally stored tokens or the GitHub Actions secrets at any time, which revokes local access immediately.

9. YouTube API Services

Don Cron Publish uses YouTube API Services. By using it, the Google Privacy Policy and the YouTube Terms of Service also apply. Additionally, this site's home page embeds the channel's videos using YouTube's privacy-enhanced mode (the youtube-nocookie.com domain); playing them also applies those same Google/YouTube policies.

10. TikTok Content Posting API

Publishing to TikTok is done through the TikTok Content Posting API (video.publish scope), subject to TikTok's developer terms and policies.

11. Contact

For questions about this policy, write to cristaldolucas01@gmail.com.
